# NVIDIA GPU acceleration on top of the core requirements.
#
#   pip install -r requirements-gpu.txt
#
# faster-whisper's only dependency is ctranslate2, and ctranslate2 declares
# NO cuda dependencies of its own -- pip will not pull these in for you, and
# without them CUDA silently fails to initialize (main.py catches that and
# tells you so, instead of quietly falling back to CPU like older scripts do).
#
# Requires cuBLAS >= 12.8 and cuDNN >= 9.7 specifically if you're on a
# Blackwell card (RTX 50-series, compute capability 12.0) -- older builds have
# no sm_120 kernels. See README.md's GPU section for the full story.

-r requirements.txt

nvidia-cublas-cu12>=12.8
nvidia-cudnn-cu12>=9.7
nvidia-cuda-nvrtc-cu12
